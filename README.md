## About

I'm an IT graduate focused on network engineering, with a growing interest in cybersecurity. I learn by building: each lab is configured from scratch in Cisco Packet Tracer, verified, and documented.

- **Certification:** CCNA 200-301 — in progress, targeting Q1 2027
- **Focus:** routing, switching, VLANs/802.1Q, inter-VLAN routing, and Linux administration
- **Security direction:** building toward cybersecurity — ACLs, port security, and network hardening
- **Next up:** STP, EtherChannel, OSPF, and an enterprise capstone
- **Daily driver:** Fedora Linux — CLI, Git, and Markdown
- **Background:** full-stack PHP/Laravel, useful for automation and clear documentation
